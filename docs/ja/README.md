# DragonPerch

**Konqi と仲間たちが、ウィンドウのタイトルバーやパネルの上を歩き回ります。
Windows および Wayland 向けに作られた、クロスプラットフォーム版の XPenguins です。**

マスコットたちはウィンドウの上端を歩いたり、タスクバーに腰かけたりします。足元のウィンドウを動かせば、行き場を失って落ちていきます。Konqi、Katie、Kori が最初から入っていますが、アートワークはスプライトパックになっているので、差し替えればどんなマスコットでも歩かせられます。実装は C++23、描画は GPU、そして無理のない範囲でできるだけ OS の素の機能に近いところで動かしています。

> 状況: **Windows に対応しています。** KDE 自身のアートワークから GPU で描かれた Konqi、Katie、Kori が、タイトルバーやタスクバーの上を歩き回ります。マスコットの上をクリックしても下のウィンドウに素通りしますし、全画面のアプリが出てくれば身を引きます。Fluent デザインに準拠したトレイメニューと設定ウィンドウも備えています。
>
> **Linux（KDE Plasma / Wayland）にも対応しています。** Wayland 向けには layer-shell オーバーレイ上に EGL で描画し、ウィンドウの位置情報は KWin スクリプトから取得します（Plasma 6 で動作確認済み）。トレイアイコンと KDE 用の設定モジュールもあります。今後の開発予定については[計画](../plan.md)をご覧ください。

英語版の README は[こちら](../../README.md)です。

## インストール

`main` ブランチのビルドごとに、常に最新の **`nightly`** プレリリースが公開されます。

| 環境 | 手順 |
|---|---|
| Debian / Ubuntu | `sudo apt install ./dragonperch_*.deb` |
| KDE Plasma をお使いの場合 | 上記に加えて `sudo apt install ./dragonperch-kde_*.deb` |
| その他の Linux | `.tar.gz` を任意の場所に展開し、`usr/bin/dragonperch-wl` を実行 |
| Windows | `.zip` を展開し、`dragonperch.exe` を実行 |

**Linux は Wayland のみ、そして今のところ実質 Plasma のみです。** オーバーレイには `zwlr_layer_shell_v1` が必要ですが、GNOME はこれを提供していません。また Wayland のクライアントは他のウィンドウがどこにあるかを知ることを許されていないため、コンポジタの内側から教えてもらう必要があり、その部分は今のところ KWin 向けにしか書かれていません。Sway や Hyprland ではマスコットは出ますが、画面の下端しか歩けません。

その Plasma でも、**インストールしたり有効にしたりする作業はありません**。DragonPerch は起動のたびに自分で KWin スクリプトを探し出し、KWin に実行を依頼します。パッケージから入れても、tar.gz を展開しても、ビルドディレクトリから動かしても同じです。どの環境で何が動くのか、うまくいかないときはどうするのかは[動作条件](requirements.md)にまとめてあります。

Windows Defender がダウンロードをブロックすることがありますが、これは誤検知です。
[理由についての詳細](packages.md#windows-defender-がダウンロードを検知する)はこちらをご覧ください。

## 使い方

トレイアイコンを右クリックすると、**一時停止**・**設定**・**終了** が出てきます。インターフェイスと呼べるものはこれで全部です。

```bash
dragonperch --pets 6      # マスコット1種類につき6体ずつ。Linux では dragonperch-wl
dragonperch --stop
```

その他のコマンドラインオプションや診断モードについては [実行のしかた](running.md) を、設定ファイルや設定ウィンドウについては [設定](settings.md) をご覧ください。
