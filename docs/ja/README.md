# DragonPerch

**Konqiと仲間たちが、ウィンドウのタイトルバーやパネルの上を歩き回ります。
Windows および Wayland 向けに作られた、クロスプラットフォーム版の XPenguins です。**

マスコットたちはウィンドウの上端を歩いたり、タスクバーに座ったりします。下のウィンドウを動かすと、足場を失って落ちていきます。デフォルトで Konqi、Katie、Kori が同梱されていますが、アートワークはスプライトパックの仕組みになっているため、好きなマスコットを歩かせることも可能です。C++23 で実装され、GPU 描画を採用し、できる限りプラットフォームのネイティブ機能に近いところで動作します。

> 状況: **Windows に対応しています。** Konqi、Katie、Kori が KDE 公式のアートワークを用いて GPU で描画され、タイトルバーやタスクバーの上を歩き回ります。マスコットへのマウスクリックは背後に透過し、全画面アプリの邪魔もしません。Fluent デザインに準拠したトレイメニューと設定ウィンドウも備えています。
>
> **Linux にも対応しています。** Wayland 向けには layer-shell オーバーレイ上に EGL で描画し、ウィンドウの位置情報は KWin スクリプトから取得します（Plasma 6 で動作確認済み）。トレイアイコンと KDE 用の設定モジュールもあります。今後の開発予定については[計画](../plan.md)をご覧ください。

英語版の README は[こちら](../../README.md)です。

## インストール

`main` ブランチのビルドごとに、常に最新の **`nightly`** プレリリースが公開されます。

| 環境 | 手順 |
|---|---|
| Debian / Ubuntu | `sudo apt install ./dragonperch_*.deb` |
| Plasma をお使いの場合 | 上記に加えて `sudo apt install ./dragonperch-kde_*.deb` |
| その他の Linux | `.tar.gz` を任意の場所に展開し、`usr/bin/dragonperch-wl` を実行 |
| Windows | `.zip` を展開し、`dragonperch.exe` を実行 |

Linux では、マスコットがウィンドウを認識できるように、初回のみ KWin スクリプトをインストールする必要があります。

```bash
./kwin/install.sh
```

その後、**システム設定 → ウィンドウ管理 → KWin スクリプト** から有効にしてください。パッケージをインストールしただけでは**有効化されず、ログイン時の自動起動も行われません**。依存関係で勝手に入ってきたプログラムが、ユーザーの画面に突然マスコットを出現させるような行儀の悪いことはしません。

Windows Defender がダウンロードをブロックすることがありますが、これは誤検知です。
[理由についての詳細](packages.md#windows-defender-がダウンロードを検知する)はこちらをご覧ください。

## 使い方

トレイアイコンを右クリックすると、**一時停止**・**設定**・**終了** のメニューが表示されます。基本的な操作はこれだけです。

```bash
dragonperch --pets 6      # マスコット1種類につき6体ずつ表示
dragonperch --stop
```

その他のコマンドラインオプションや診断モードについては [実行のしかた](running.md) を、設定ファイルや設定ウィンドウについては [設定](settings.md) をご覧ください。
